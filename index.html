In-Context Learning World Models for Robot Dual-Arm Manipulation of Soft Garment with Partial Observations

Hengyi Sim1,2 Quentin Rouxel1,2 Dennis Hong4 Darwin Caldwell5 Fei Chen1,2
2Department of Mechanical and Automation Engineering, T-Stone Robotics Institute, The Chinese University of Hong Kong, Hong Kong

Abstract


Robust manipulation of soft objects, such as garments, is a critical skill for service and household robots to adopt, but remains challenging due to its high-dimensional state space, and material-dependent deformations. Humans address this challenge by using mental world models that "imagine" the shape and material properties from partial observations, which enables them to predict how actions affect future states. As such, embedding such world models in robots allows for better generalization in manipulating a wide variety of garments in the real world. However, learned world models typically require large amounts of real world data that is strenuous to collect, and a mechanism to infer latent properties that govern dynamics. We present a Soft-Object World Model that performs generative full-state estimation and action-conditioned dynamics prediction using a transformer backbone trained on large-scale simulated soft object interactions, with measures to mitigate the sim-to-real gap. By learning to infer latent shape and material cues through in-context learning over a variable-length partial point-cloud history, the model generalizes across robot embodiments, material parameters, garment types and shapes, and manipulation coordination modes without weight updates. The world model is then integrated with a Goal-Conditioned action planner for motion synthesis. We validate the approach in simulation and real world for bimanual garment folding, reporting improvements in reconstruction fidelity, prediction accuracy, and task success.

Methodology

Objectives:

  • Infer a dense 3D soft-object state (point cloud) from partial point-cloud observations.
  • Predict future states over a desired horizon, conditioned on robot actions, estimated state history and a context demonstration.
  • Use variable-length context demonstrations so the model can infer latent shape/material properties for dynamics prediction without weight updates.
  • Integrate the world model with a goal-conditioned action planner to generate action proposals and select the one expected to reach the target configuration.

Challenges:

  • State Estimation: Soft objects have high DOFs, and important parts are often occluded, making it hard to infer the full object state from partial point-cloud observations.
  • Dynamics Prediction: Deformations depend strongly on latent material properties, current unseen shape, and contact/grasp conditions, so the same action can lead to different outcomes.

Main Ideas

  • Introduce Soft Object World Model that reconstructs full object states from partial observations and predicts action-conditioned multi-step deformations.
  • Propose Test-time in-context adaptation to infer latent shape/material cues for dynamics prediction without any weight updates.
  • Evaluate in simulation for bimanual garment folding, and validate on the real X-trainer and TienKung humanoid robot.

Soft Object World Model

  • The soft object world model reconstructs full garment state from partial point clouds using conditional flow matching.
  • It uses a transformer with point-cloud tokenization and cross-attention conditioning to generate the dense 3D garment.
  • It is trained in simulation with randomized interactions and material properties to improve robustness.
  • It serves as an evaluator that scores candidate action trajectories by their predicted terminal state accuracy.

Cross Embodiment Experiments

  • Cross-embodiment transfer is validated by running the method on a humanoid robot as well.
  • The approach generalizes across robots because it uses a shared object point-cloud state representation and an embodiment-agnostic action space.
  • The humanoid experiments show strong real-world folding performance with successful demonstrations across garment categories.
